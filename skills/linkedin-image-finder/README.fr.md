# LinkedIn Image Finder

[Catalogue](../../README.md) · [Français](README.fr.md) · [English](README.md)

Choisir un visuel pour un post puis confier la recherche au spécialiste mèmes.

<a id="install"></a>
## Installation

```text
Installe linkedin-image-finder et linkedin-meme-finder
Repository: https://github.com/kconde2/barakasocial-linkedin-claude-skills
Folders: skills/linkedin-image-finder and skills/linkedin-meme-finder
Copy each complete folder, including references/ and scripts/.
Compare existing installations before replacing them. Preserve personal preferences.
```

[ZIP preview.16](https://github.com/kconde2/barakasocial-linkedin-claude-skills/releases/download/v0.1.0-preview.16/linkedin-image-finder.zip)

[Installer aussi Meme Finder](../linkedin-meme-finder/README.fr.md).

## Utilisation

```text
Utilise linkedin-image-finder. Propose cinq mèmes avec leurs images et leurs textes pour ce post :
[coller le post]
```

Recherche web nécessaire. Montage selon les outils disponibles dans ton agent. Pas de clé API Imgflip ni de compte BarakaSocial requis pour un texte fourni. Le connecteur est nécessaire pour lire un post enregistré dans BarakaSocial. Cinq propositions par défaut ou le nombre demandé. Rien ne sera publié.
