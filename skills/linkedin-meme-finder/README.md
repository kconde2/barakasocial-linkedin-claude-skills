# LinkedIn Meme Finder

[Catalogue](../../README.md) · [Français](README.fr.md) · [English](README.md)

Search the web for memes, show images and captions, then edit the selected candidate.

## Installation

```text
Install linkedin-meme-finder
Repository: https://github.com/kconde2/barakasocial-linkedin-claude-skills
Folders: skills/linkedin-meme-finder
Copy each complete folder, including references/ and scripts/.
Compare existing installations before replacing them. Preserve personal preferences.
```

[ZIP preview.15](https://github.com/kconde2/barakasocial-linkedin-claude-skills/releases/download/v0.1.0-preview.15/linkedin-meme-finder.zip)

## Usage

```text
Utilise linkedin-meme-finder. Propose cinq mèmes avec leurs images et leurs textes pour ce post :
[coller le post]
```

Requires web search. Editing depends on the tools available in your agent. No Imgflip API key or BarakaSocial account is needed for pasted text. Reading a saved BarakaSocial post requires its connector. Five candidates by default or your requested count. Nothing is published.
