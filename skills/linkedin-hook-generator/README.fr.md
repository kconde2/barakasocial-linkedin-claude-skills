# LinkedIn Hook Generator

[← Tous les skills](../../README.fr.md) · [English](README.md)

Trouve une ouverture qui donne envie de lire la suite à partir des faits de ton sujet ou de ton brouillon.

**Prérequis :** un sujet, des notes ou un brouillon. Aucun compte BarakaSocial nécessaire.

[Installer](#install) · [Utiliser](#use) · [Exemples à copier](#examples) · [Personnaliser](#personalize)

<a id="install"></a>
## Installer ce skill

**Dans Claude Code ou Codex**, copie cette demande dans une conversation :

```text
Installe linkedin-hook-generator dans mes skills personnels pour ce client.
Dépôt : https://github.com/kconde2/barakasocial-linkedin-claude-skills
Dossier : skills/linkedin-hook-generator
Utilise la version du dépôt et copie SKILL.md avec tout le dossier references/.
Lis les instructions avant l'installation. Si ce skill existe déjà,
compare son origine et son contenu avant de le remplacer.
Conserve mes préférences personnelles et ma configuration MCP.
```

**Dans Claude avec import ZIP :** télécharge le [ZIP preview.10](https://github.com/kconde2/barakasocial-linkedin-claude-skills/releases/download/v0.1.0-preview.10/linkedin-hook-generator.zip) puis importe l'archive complète dans la gestion des skills. Elle contient `SKILL.md` et les 2 références communes. [Options d'installation](../../docs/guide.fr.md).

[Voir les options d'installation et de mise à jour](../../docs/guide.fr.md)

<a id="use"></a>
## Utiliser le skill

Après installation, copie cet exemple en remplaçant la matière par la tienne :

```text
Utilise linkedin-hook-generator.
Je parle aux freelances. Un client ajoute une demande après la validation du devis. Propose 3 accroches sobres sans inventer de faits.
```

**Ce que tu obtiens :** 3 accroches comparées dans un tableau et une recommandation. Une ouverture existante efficace peut être conservée.

Le skill répond dans la langue demandée. Il n'enregistre ni ne publie de post.

<a id="examples"></a>
## Demandes prêtes à copier

Ces demandes sont à coller dans la conversation après installation. Remplace les éléments entre crochets par tes informations. Ce ne sont pas des commandes de terminal.

### Améliorer un post existant

```text
Utilise linkedin-hook-generator.
Propose 3 accroches pour ce post. Compare-les dans un tableau et recommande la plus adaptée. Garde les faits et ne réécris pas le corps :
[colle ton post]
```

### Partir de notes

```text
Utilise linkedin-hook-generator.
Mon public : [public]. Mon idée : [idée]. Mes faits : [faits disponibles]. Propose des accroches sans inventer de scène. Si une information essentielle manque, demande-la.
```

### Retravailler une accroche choisie

```text
Utilise linkedin-hook-generator.
Retravaille uniquement cette accroche : [accroche]. Je veux un ton [ton souhaité]. Voici le post pour vérifier que la promesse correspond au contenu :
[post]
```

<a id="personalize"></a>
## Personnaliser

Tu peux préciser ton public, ton ton et ce que tu veux éviter. Le skill demande uniquement ce qui manque. Cette étape est facultative.

> Personnalise ce skill pour les dirigeants de petites agences. Ton direct, humour léger et aucune question finale automatique. Garde ces choix dans cette conversation.
