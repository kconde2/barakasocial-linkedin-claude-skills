# LinkedIn Hook Generator

[← All skills](../../README.md) · [Français](README.fr.md)

Find an opening that makes readers want to continue, using the facts in your topic or draft.

**Requires:** a topic, notes or a draft. No BarakaSocial account needed.

[Install](#install) · [Use](#use) · [Copyable examples](#examples) · [Personalize](#personalize)

```text

Repository: https://github.com/kconde2/barakasocial-linkedin-claude-skills
Folder: skills/linkedin-hook-generator
Use the repository version and copy SKILL.md with the entire references/ folder.
Read the instructions before installing. If this skill already exists,
compare its origin and contents before replacing it.
Preserve my personal preferences and MCP configuration.
```

**In Claude with ZIP import:** download the [preview.10 ZIP](https://github.com/kconde2/barakasocial-linkedin-claude-skills/releases/download/v0.1.0-preview.10/linkedin-hook-generator.zip) and upload the complete archive through skill management. <a id="use"></a>
## Use the skill

After installation, copy this example and replace the material with your own:

```text
Use linkedin-hook-generator.
My audience is freelancers. A client adds a request after approving the estimate. Suggest 3 understated openings without inventing facts.
```

**What you get:** 3 openings compared in a table and one recommendation. An effective original opening can be kept.

The skill responds in the requested language. It does not save or publish posts.

<a id="examples"></a>
## Ready-to-copy requests

Paste these requests into your conversation after installation. Replace bracketed placeholders with your information. These are not terminal commands.

### Improve an existing post

```text
Use linkedin-hook-generator.
Suggest 3 hooks for this post. Compare them in a table and recommend the best fit. Preserve the facts and do not rewrite the body:
[paste your post]
```

### Start from notes

```text
Use linkedin-hook-generator.
My audience: [audience]. My point: [idea]. My facts: [available facts]. Suggest hooks without inventing a scene. Ask if essential information is missing.
```

### Refine a selected hook

```text
Use linkedin-hook-generator.
Refine only this hook: [hook]. Use a [desired tone] voice. Here is the post so you can check the opening matches its content:
[post]
```
